# Contributing to MindSphere

Thank you for your interest in contributing to MindSphere! This guide explains how to get started and submit your changes.

## Getting Started

1. Fork the MindSphere repository to your GitHub account.
2. Clone your fork to your local computer if you want to work locally.
3. Read the main README.md file for project features, setup instructions, and development requirements.

## Project Structure

- `client/` — React and Vite frontend.
- `server/` — Flask backend.

## Making Changes

1. Create a separate branch for your changes.
2. Make a focused improvement or fix.
3. Keep your changes clear and easy to review.
4. Update documentation when needed.
5. Test your changes before submitting them.

## Testing

For frontend changes, run the following commands from the `client/` directory:

- `npm run lint`
- `npm run build`

For backend changes, consult the main README.md for setup instructions and the available test script.

## Good Practices

- Never commit API keys, passwords, or `.env` files containing secrets.
- Do not use real sensitive mental-health information for testing.
- Follow the existing project structure and coding conventions.
- Describe your changes clearly.
- Report any known limitations in your pull request.

## Submitting a Pull Request

1. Commit your changes to your fork.
2. Push your branch to GitHub if working locally.
3. Open a pull request against the original MindSphere repository.
4. Explain what you changed and how you tested it.
5. Respond politely to feedback from maintainers.

Thank you for helping improve MindSphere!
